# 光の世話係（FF14 Raid Companion）

Discord上でFF14の固定活動を支援する、個人運営の無料Botです。

## 主な機能

- **予定と出欠**：予定を登録すると、参加者は月間カレンダーから○・△・×で出欠を回答できます。予定は「ブラウザで開く」「Discord内で開く」「簡易表示」から開けます。
- **通知**：未入力者通知、活動開始前通知、△リマインダーを管理者が設定できます。△リマインダーは、回答が△のメンバーだけに再確認をお願いする通知です。初期状態はOFFで、△の理由は通知に含まれません。
- **固定ルール**：サーバーの固定ルールに同意したメンバーに、参加者向けの部屋を表示します。管理者がルールを変更した場合は、もう一度同意が必要です。
- **そのほか**：ロット管理、攻略資料、お知らせ・アンケートなどから、管理者が「使用する機能」で必要なものを選んで使えます。

## プライバシー

- 保存したデータを期間に応じて自動で削除する仕組みがありますが、現在は自動削除を行っていません。始めるときは、事前にプライバシーポリシーとご案内でお知らせします。
- 運用のための記録（ログ）には、DiscordのサーバーIDや利用者IDをそのまま残しません。

## Botをサーバーへ追加

[光の世話係をDiscordサーバーへ招待する](https://discord.com/oauth2/authorize?client_id=1530461617786060840)

招待先のDiscordサーバーで、アプリを追加できる権限が必要です。
本BotはDiscordの「管理者」（Administrator）権限を要求しません。
要求する権限は、チャンネルの管理・ロールの管理・チャンネルを見る・メッセージを送信・埋め込みリンク・メッセージ履歴を読む・メッセージの管理・@everyoneへのメンションです。

追加後、Botは`管理者専用`カテゴリに規約同意用のチャンネルを作成します。
「サーバーの管理」権限を持つ管理者が利用規約とプライバシーポリシーを確認して同意し、セットアップ方法（スケジュールだけ／かんたん設定／標準設定／カスタム設定）を選ぶと、セットアップが始まります。使い方は[使い方ガイド](https://web--ff14-raid-companion-web--wqwnxcrvmsz7.code.run/guide)で、画面の見本つきで説明しています。
専用チャンネルを作れない場合は、サーバー管理者が `/setup` を実行すると同じ手順を開始できます。
