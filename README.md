# 光の世話係（FF14 Raid Companion）

Discord上でFF14の固定活動を支援する、個人運営の無料Botです。

## 光の世話係 v0.13.0

**安定性**
- Botの更新や再起動のときに、処理中のリマインダー（カスタム通知・予定の通知）が終わるのを待ってから停止するようになりました。更新の前後で、通知の重複や処理の取りこぼしが起きにくくなります。

**予定を登録する画面**
- 開き方を、ブラウザで開く・Discord内で開く・簡易表示から選べます。毎回選ぶこともできます。

**プライバシー**
- 保存データを期間に応じて整理する仕組みを追加しました。現在は対象の件数を確認しているだけで、自動削除は行っていません。自動削除を始めるときは、事前にプライバシーポリシーとご案内でお知らせします。
- 運用のための記録（ログ）に、DiscordのサーバーIDや利用者IDをそのまま残さないようにしました。
- プライバシーポリシーを更新しました（2026年9月30日）。

## Botをサーバーへ追加

[光の世話係をDiscordサーバーへ招待する](https://discord.com/oauth2/authorize?client_id=1530461617786060840)

招待先のDiscordサーバーで、アプリを追加できる権限が必要です。
本BotはAdministrator権限を要求しません。
要求する権限は、チャンネルの管理・ロールの管理・チャンネルを見る・メッセージを送信・埋め込みリンク・メッセージ履歴を読む・メッセージの管理・@everyoneへのメンションです。

追加後、Botは`管理者専用`カテゴリに規約同意用のチャンネルを作成します。
「サーバーの管理」権限を持つ管理者が利用規約とプライバシーポリシーを確認して同意し、作成する部屋を選ぶと、選んだ部屋のセットアップが始まります。
専用チャンネルを作れない場合は、サーバー管理者が `/setup` を実行すると同じ手順を開始できます。
